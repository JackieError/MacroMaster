# 돈의 흐름 — 실제 데이터로 읽는 매크로 상관관계

지표를 하나씩 정의하는 글로서리가 아니라, **실제로 있었던 국면을 실측 데이터로 다시 짚어보는**
매크로 학습 커리큘럼이다.

- 배포: https://jackieerror.github.io/MacroMaster/curriculum/
- 작업본 Artifact: https://claude.ai/code/artifact/c421b29c-d3f0-4d98-8020-6240d7bf8ee0
- 작업 규칙: `../harnesses/curriculum.md`

`index.html` 하나로 동작하는 정적 SPA다. 빌드 과정이 없고, 런타임에 외부 API를 호출하지 않는다.
모든 데이터는 아래 원본에서 미리 받아 HTML 안에 상수로 구워져 있다.

## 구성

각 사례는 다음으로 이루어진다.

| 요소 | 내용 |
|------|------|
| 차트 | 실측 데이터 inline SVG. 호버 크로스헤어·툴팁, 이벤트 마커, NBER 침체 구간 음영 |
| 서술 | 무엇이 왜 일어났고 어떻게 다음 지표로 연쇄했는지 |
| 실전 박스 | "실전에서 이렇게 읽는다" 요약 |
| 심층 아코디언 | 메커니즘 / 패턴이 깨졌던 순간들 / 반론·다른 시각 / 지금 우리는 어떤 국면에 |

사이드바에서 카테고리별로 사례를 넘나들고, 하단의 **지표 사전**(슬라이드오버)에서
용어를 찾아볼 수 있다. 용어사전은 어디까지나 보조 기능이고, 본체는 사례 분석이다.

## 데이터 원본

`data/` 아래에 사례에 쓰인 실측 원본이 그대로 들어 있다.

### FRED (`data/fred/`)

**API 키가 필요 없다.** 공개 CSV 엔드포인트로 받는다.

```bash
curl -s "https://fred.stlouisfed.org/graph/fredgraph.csv?id=FEDFUNDS"
```

> 공식 API(`api.stlouisfed.org`, 키 필요)로 15개 시리즈를 전량 재수집해 값 단위로 diff한 결과,
> 공개 CSV와 **완전히 동일**했다(차이는 `"3.63"` vs `"3.6300000000"` 같은 문자열 포맷뿐).
> 단순 시계열 수집에 키를 쓸 이유가 없다.

| ID | 내용 | 주기 |
|----|------|------|
| `FEDFUNDS` / `DFF` | 연준 기준금리 (월 / 일) | 월·일 |
| `DEXKOUS` | 원/달러 환율 | 일 |
| `T10Y2Y` | 10년-2년 국채 금리차 | 일 |

### Yahoo Finance (`data/yahoo/`)

chart API를 `curl`로 직접 호출. `^GSPC`(S&P500), `^KS11`(코스피), `^KQ11`(코스닥),
`^SOX`(필라델피아 반도체), `EEM`(신흥국 ETF), `GC=F`(금), `BTC-USD`(비트코인),
`005930.KS`(삼성전자), `000660.KS`(SK하이닉스), `^N225`(닛케이225).

> Yahoo chart API를 `curl`로 직접 호출할 땐 `-A "Mozilla/5.0 ..."`로 User-Agent를 지정해야
> 한다 — 없으면 429가 뜬다. 장기간 월간 데이터는 `range=max&interval=1mo`가 아니라
> `period1`/`period2`(유닉스 타임스탬프)를 명시해서 받아야 한다 — `range=max` 방식은
> 최근 구간이 분기 단위로 뭉개지는 문제가 있었다(실제로 `^N225`에서 발견).

### Stooq (`data/stooq/`)

백업 소스. `https://stooq.com/q/d/l/?s=<심볼>&i=d`

## 확인된 제약

이미 검증한 것들이다. 같은 시도를 반복하지 않는다.

- **`DATA_GO_KR_KEY`로 코스피/코스닥 지수는 못 받는다** — 지수 API가 403(미승인)이다.
  개별 종목 일별시세(`GetStockSecuritiesInfoService/getStockPriceInfo`)는 정상 작동하지만,
  삼성전자·SK하이닉스도 결국 **Yahoo Finance(`005930.KS`/`000660.KS`)가 더 간단해서 그쪽을 썼다**
  — data.go.kr 개별종목 엔드포인트는 검증만 하고 실사용은 안 함.
  (PROJECT_STATE.md의 "섹터 지수 API 별도 활용신청 필요"와 같은 맥락)
- **정적 페이지라 런타임 API 호출이 없다.** 원본 Artifact도 CSP 샌드박스로 외부 fetch가 막힌다.
  Pages 배포본에서 `/api/*`가 안 되는 것과 같다.
- **`WebFetch`류로 시계열을 받지 않는다.** 모델이 HTML을 요약하는 과정에서 숫자가 손실·왜곡된다.
- 하이일드 스프레드(`BAMLH0A0HYM2`)는 FRED에 2023년 이후만 있어 장기 시계열이 있는 `BAA10Y`로 대체했다.

## 스크립트

`scripts/` — 원본 CSV·JSON을 차트용 시계열로 가공한 스크립트다(`process.py`, `process2.py`,
`stats.py`). 작업 당시 데이터 파일과 같은 디렉토리에서 실행하는 것을 전제로 쓰여 있으므로,
다시 돌릴 때는 경로를 맞춰야 한다. 완성된 빌드 파이프라인이 아니라 참고용 기록이다.

## 데이터 갱신

일간 데이터는 파일 크기와 렌더링 성능을 위해 주간·월간으로 다운샘플링하되,
**2008 금융위기 · 2020 팬데믹 · 2022 긴축** 같은 실제 변곡점은 반드시 살린다.

본문에 인용되는 모든 수치(%, 배수, 날짜)는 이 데이터에서 직접 계산한 값이어야 한다.
데이터를 갱신하면 서술 속 숫자도 함께 다시 계산한다.

## 주의

이 페이지는 투자 조언이 아니라 매크로 지표를 실제 사례로 읽는 연습 자료다.
과거의 상관관계가 미래에도 반복된다는 보장은 없다 — 그래서 각 사례마다
"패턴이 깨졌던 순간들"과 "반론" 섹션을 함께 둔다.
