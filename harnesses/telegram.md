# Telegram intelligence harness

## 현재 상태

봇: `@macroerrorbot`. Bot API 연결은 성공했으며 봇이 받은 새 메시지만 분석한다.

## 처리 단계

1. 메시지 원문과 채팅·시간·포워드 출처 저장
2. URL·문장 유사도로 반복 포워딩 제거
3. 광고·리딩방·출처 불명 자료 표시
4. 기업·산업·매크로·사건 엔티티 추출
5. 사실 주장과 작성자 의견 분리
6. 언급 증가율과 출처 다양성 계산
7. 가격·공시로 확인되지 않으면 `관심 신호`로만 표시

감성점수만으로 매수/매도 의견을 만들지 않는다. 쏠림은 선행정보일 수도, 후행 과열일 수도 있으므로 가격 반응과 출처 독립성을 함께 본다.
