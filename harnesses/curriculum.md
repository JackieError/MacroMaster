# Curriculum harness

매크로 지표 간 상관관계를 **실제 과거 사례**로 학습하는 정적 커리큘럼(`curriculum/`) 담당.

Market Note 대시보드(`index.html`)와는 별개의 산출물이다. 대시보드는 "오늘의 시장을 읽는 순서"를,
커리큘럼은 "과거 국면을 데이터로 다시 짚어보는 학습"을 맡는다. 서로 코드를 공유하지 않는다.

## 콘텐츠 원칙

1. **지표 사전이 아니라 사례 분석이다.** 지표를 하나씩 정의하는 글로서리를 만들지 않는다.
   "2022년 3월 연준이 금리를 올리자 → 달러가 강세로 → 신흥국 통화가 밀렸다" 같은
   실제 국면을 데이터로 다시 짚는 방식이어야 한다. 용어사전은 보조 참고 기능으로만 둔다.
2. **모든 숫자는 실측 데이터.** 차트도 본문 수치(%, 배수, 날짜)도 전부 `curriculum/data/`의
   실제 데이터에서 직접 계산한다. 그럴듯한 합성 숫자 금지. 못 구하면 명시하고 프레이밍을 바꾼다.
3. **성공 사례만 보여주지 않는다.** 각 사례에 신호가 틀렸던 반례와 회의적 시각(반론)을 함께 넣는다.
   사용자가 지표를 맹신하게 만드는 콘텐츠는 실패한 콘텐츠다.
4. **투자 조언이 아니다.** 확정적 예측 대신 "이 신호는 이런 국면을 가리키지만 한계도 있다" 톤.
   `config/analysis-policy.json`의 정직성 규칙과 AGENTS.md의 "가격 동행만으로 인과관계를
   단정하지 않는다"를 그대로 따른다.

## 사례 구성

각 사례는 다음으로 구성한다.

- 실측 데이터 SVG 차트 + 이벤트 마커 + 침체 구간 음영
- 무엇이 왜 일어났고 어떻게 연쇄했는지 서술
- "실전에서 이렇게 읽는다" 요약 박스
- **4단 심층 아코디언**: 메커니즘 / 패턴이 깨졌던 순간들 / 반론·다른 시각 / 지금 우리는 어떤 국면에

## 기술 제약

- 차트는 외부 CDN(D3, Chart.js) 없이 **순수 inline SVG + vanilla JS**로 구현한다.
- 정적 페이지다. **런타임에 외부 API를 호출하지 않는다** — 데이터는 미리 받아 HTML에 굽는다.
  (Pages 배포본에서 `/api/*`가 동작하지 않는 것과 같은 이유이며, 원본 아티팩트도 CSP로 막힌다.)
- **API 키를 이 디렉토리 어떤 파일에도 넣지 않는다.** 수집 단계에서만 쓴다. AGENTS.md 절대 규칙.
- 라이트/다크 모드, 데스크톱/모바일 반응형을 모두 지원한다.

## 데이터

`curriculum/data/` — 사례에 쓰인 실측 원본. 자세한 시리즈 목록과 API 제약은
`curriculum/README.md` 참고. 요점:

- **FRED는 API 키가 필요 없다.** 공개 CSV(`fredgraph.csv?id=<ID>`)와 공식 API 결과가
  15개 시리즈 전량 diff에서 값이 동일했다(차이는 문자열 포맷뿐).
- **`DATA_GO_KR_KEY`로 코스피/코스닥 지수는 못 받는다**(403). 개별 종목 시세는 된다.
  지수는 Yahoo Finance로만 확보 가능. — PROJECT_STATE.md의 "섹터 지수 API 별도 신청" 제약과 동일 맥락.
- 시계열 수집에 `WebFetch`류를 쓰지 않는다. 요약 과정에서 숫자가 손실된다. `curl`로 직접 받는다.
